# 📦 СкладCRM — Система учёта и эксплуатации складских помещений

Веб-платформа для автоматизации управления складской недвижимостью: паспортизация помещений, ведение договоров аренды, контроль показаний приборов учёта (ЖКУ), диспетчеризация сервисных заявок и оценка надёжности контрагентов.

## ⚙️ Что можно протестировать прямо сейчас (Функционал прототипа)

В системе реализованы **два изолированных ролевых контура** со сквозной синхронизацией действий в браузере *(при нажатии `F5` данные возвращаются к исходному состоянию для удобства повторного тестирования)*:

### 1. Кабинет Управляющего
* **Реестр помещений и P&L:** фильтрация по комплексам (*Логопарк «Север» / «Юг»*), корпусам, статусам и температурному режиму; живой пересчёт доходов, расходов на ремонт и чистой прибыли.
* **Паспортизация и договоры:** добавление и редактирование техпаспорта склада, привязка счётчиков, создание нового контрагента, назначение даты очного выезда на подписание, загрузка скана оригинала, генерация PDF и смена статуса склада (*Свободен / Занят / Ремонт*).
* **Контрагенты:** реестр арендаторов, просмотр задолженности, истории прошлых/текущих аренд и статус надёжности (*Рекомендован / Есть задержки / Чёрный список* с предупреждением при повторном заселении).
* **Счётчики (ЖКУ):** приёмка переданных показаний с просмотром фото прибора или отклонение с указанием причины.
* **Заявки (Service Desk):** уровни срочности SLA (*Аварийная до 2 ч / Срочная до 24 ч / Плановая*), просмотр фото поломки, ручной ввод стоимости работ (автоматически учитывается в расходах P&L) и закрытие заявок.

### 2. Личный кабинет Арендатора
* **Мой склад:** просмотр одного или нескольких арендованных боксов, параметров и статусов договоров (включая дату назначенной встречи), скачивание договора.
* **Счетчики:** пакетная передача показаний сразу по всем приборам помещения (свет, вода, тепло) с загрузкой подтверждающего фото и отображением причины отказа при отклонении.
* **Заявки:** подача обращений с выбором уровня срочности, описанием проблемы и прикреплением фото + история статусов.

## 🛠 Технологический стек

* **Frontend:** React 18, React Router v6, Vite, Tailwind CSS, Lucide Icons
* **Backend:** Python, FastAPI, SQLAlchemy, Alembic *(в разработке)*
* **База данных:** PostgreSQL (3НФ, защита от пересечения дат договоров `EXCLUDE USING gist`)
* **Инфраструктура:** GitHub Actions, GitHub Pages
